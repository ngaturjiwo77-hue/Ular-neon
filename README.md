# 🐍 Ular Neon (Neon Snake) ✨

Selamat datang di repositori **Ular Neon**! Ini adalah versi modern dari permainan klasik *Snake* yang dibangun menggunakan **React Native** dan **Expo**. Game ini mengusung tema visual *Cyberpunk/Neon* dengan warna-warna cerah menyala di atas latar belakang gelap.

## 🌟 Fitur Utama
*   **🎮 Mekanik Klasik:** Kumpulkan makanan untuk memanjangkan ular dan dapatkan skor tertinggi!
*   **🕹️ Kontrol Ganda:** Mendukung usapan layar (*Swipe Gestures*) dan tombol arah virtual (D-Pad).
*   **⚡ Pilihan Kesulitan:** Tiga tingkat kecepatan (Lambat, Sedang, Cepat) yang bisa diubah kapan saja.
*   **💾 Penyimpanan Lokal:** Skor tertinggi (*High Score*) otomatis tersimpan di perangkat Anda.
*   **🤖 CI/CD Otomatis:** Proyek ini dilengkapi dengan skrip **GitHub Actions** yang secara otomatis meracik kode menjadi file Android APK (`app-release.apk`) siap instal setiap kali ada pembaruan kode.

## 📱 Cara Menginstal dan Memainkan (Android)
Karena game ini diracik secara otomatis oleh server GitHub, Anda bisa langsung mengunduh file APK-nya tanpa perlu melakukan *build* manual:

1. Buka tab **[Actions](../../actions)** di atas repositori ini.
2. Klik pada proses *build* terbaru yang memiliki centang hijau (✅).
3. Gulir ke bagian paling bawah ke menu **Artifacts**.
4. Klik dan unduh file bernama **`UlarNeon-Release-APK`**.
5. Ekstrak file `.zip` yang terunduh di HP Anda.
6. Instal file **`app-release.apk`** (pastikan Anda mengizinkan instalasi dari sumber tidak dikenal di pengaturan HP Anda).
7. Selamat bermain!
